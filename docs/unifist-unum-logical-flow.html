Unifist Unum Mission

To work together with an external executive function instead of centralized leadership.

We want to figure out how to get shit done working together without having to answer to a boss, only to each other.

Unifist Unum Logical Flow

Ground Up

Unifist Unum is based entirely on the ground up shit not working.

It's not based on some ideology. It's not based on some grand vision. It's based on working systems that immediately deliver value to both the organization (Unum) and its members (Unifist).

The first rule of Unifist Unum is everyone, including the org, should be getting back more than they're putting in.

No faith. No hope. No promises. It works out of the gate or we don't work at all.

The shit bucket principle

We start with the shit bucket principle, literally.

The bare bones of any organization is a list of things that aren't right and one person doing one process to make each right.

What we do to improve that process is separate specialized processes from that universal one.

We only do this if it is more efficient to do so.

Scat

In Cumulus, an issue is called a Scat.

A funny word for shit, without swearing.

The goal of a Scat is to be Flushed.

Something you gotta deal with, and then you don't have to deal with it anymore.

A Flush can have one or more Scats.

Bucket

A Bucket allows us to group related Scats before Flushing them at once.

The other half of the shit bucket principle.

We create a Bucket from repeated Flushes with multiple Scats.

We see this efficiency already there, and we seek to improve it further.

The evolve through failure principle

In Unifist Unum, we act on failure, and to fail to do so, we act on that failure to evolve.

If an organization cannot handle issues, they will pile up and continue to do so until they are handled.

We must add analysis of failures to our system, adapting to handle them.

Change must come from within.

Bolts are Proactive

With Scats alone, we can only be reactive.

Someone goes to cook and there's no butter. That's not a great time to find out. We didn't know before so it wasn't on the list.

With Bolts, we can be proactive.

We have a list of staples checked before we go shopping, including butter. There is always butter available after shopping.

Add Bolts to existing Buckets to turn oh shits into just regular shits.

Unifist Unum Logical Flow

Strikes

Strikes are attempts to Flush a Scat.

A Flush is the resolving of a Scat. A Strike is a record to allow that extra time to try.

Strikes can come from a Scat (should), a Bolt, a Rod (forthcoming), or nothing at all.

More important to record what you can.

Just as a Bolt is like a project, a Strike is like a ticket.

Unifist Unum Logical Flow

Repeated Strikes create Rods

Strikes start as ways to learn and work on Sparks.

Once figured out, they get easier and easier because we know what's required.

Eventually we create Rods, which contain those requirements.

A Rod has a Strike all ready to start, just needs an someone to do it.

Flushing a Bucket is actually a Rod.
